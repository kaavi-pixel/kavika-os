## Gate decision

### Archive-reported Windows preflight, 2026-10-15

- CPU: AMD Ryzen 7 8840HS, 16 logical processors.
- Windows-reported physical memory: 15.3 GiB; this is the script's `Win32_ComputerSystem.TotalPhysicalMemory` value, not the same measure as installed-module capacity and not a usable guest-memory budget. The output key `installedMemoryGiB` is misleading; interpret it as reported system physical memory until the tool is revised and retested.
- Graphics controller name: AMD Radeon TM Graphics; not a full GPU inventory.
- C: capacity 952.73 GiB; free 737.03 GiB at collection time. This does not
  establish space on an external test disk or authorise repartitioning.
- Firmware virtualisation indicator: true; active hypervisor indicator: true.
- Second-level address translation indicator: false. Treat this as unresolved
  under the active hypervisor; verify Linux KVM support before drawing a conclusion.
- Host Windows edition: Windows 11 Home Single Language. Guest edition and
  licensing are separate decisions.

The archive says the script completed without changing system configuration. Static review found only queries, formatting, and output/error handling, but this does not reproduce or certify the recorded execution. These results cover preliminary Windows observations, not Linux device support or VM performance.

### Static-review limits and follow-up

- `installedMemoryGiB` names a different concept from the property queried; distinguish system-reported memory from physically installed module totals before relying on the field.
- GPU controller names and fixed-volume summaries are not complete device, driver, or external-test-disk validation.
- False/null virtualisation properties and the active-hypervisor flag must remain raw observations, not automatic capability failures or passes.
- CIM queries currently share one catch-all handler. A query failure may discard the whole report and hides the failing query; test this before considering the tool a reliable diagnostic.
- Review found no explicit writes or settings changes in the script. Parser/runtime tests, command availability, query permissions, and normal/error-path execution remain untested here.

M0 remains open. Record failures and unknowns explicitly and link reviewed evidence
to issue #1 before closure. Keep the already-approved Surface/media erase scope
distinct from successful hardware validation or identification of the connected
disk; it does not extend to the HP internal drive or firmware-security changes.
